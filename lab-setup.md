# Lab Setup and Capture Procedure

## Recommended topology
Use two virtual machines connected through a host-only or isolated virtual network:
- VM 1: Kali Linux (analysis workstation)
- VM 2: Linux test host (generates benign traffic)

Keep the network isolated from production and public networks. A single-machine loopback lab is also supported.

## Capture authorization
Capture only traffic generated by you in this lab or traffic for which you have written authorization. Do not capture shared Wi-Fi, office, college, or public network traffic.

## Single-machine setup
1. Install Wireshark, tcpdump, and Snort.
2. Confirm the loopback interface with `ip -br addr`.
3. Start a local test HTTP server: `python3 -m http.server 8000 --bind 127.0.0.1`.
4. Capture loopback traffic using the command in the main README.
5. Generate a few ICMP and HTTP requests to `127.0.0.1`.
6. Stop capture and the local server.

## Capture metadata to record
- Date and time (include timezone)
- Host operating system and version
- Interface name
- Capture filter
- Capture duration
- Tool and version
- Lab topology
- Any known limitations

## File handling
Store PCAP files in `captures/`. PCAPs may contain sensitive data. Review and sanitize them before sharing; do not upload real user traffic.
